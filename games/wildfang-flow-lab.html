Your body is the battlefield.

This simulator plays the actual game engine with four different control policies. It measures real loops, tail cuts, length gained and lost, earned levels, and survival across seeded worlds. These are repeatable bot runs, not a claim that human play has been perfectly balanced.

Repeat the experiment.

From the game folder, run node qa/simulate-flow.cjs --full. It regenerates this report using the current HTML engine. To inspect a case at the game's full update rate, use node qa/simulate-flow.cjs --profile=hunter --seed=3400 --fps=60 --out=flow-60fps.json.

Agents choose evolutions by preference and react at different intervals. Foragers chase food and use the tail defensively; hunters steer around fixed centers to close real loops; explorers hunt opportunistically and favor food ahead. Agents harden when stronger jaws begin chewing or resist a loop. Long bodies slow down, and each evolution sheds length. The idle control only travels straight and accepts level choices. No agent receives extra length, free XP, automatic captures, or altered enemy rules. A failed hunt can snowball into a short-body escape; these policies are simple, not optimal players.
